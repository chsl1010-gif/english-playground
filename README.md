# 영어 놀이터

영어를 처음 배우는 아이들을 위한 그림·소리 단어 게임이에요. 영어를 몰라도 그림을 누르면 발음이 나와요.

**바로 하기: https://english-playground.vercel.app**

## 놀이 방법

- 처음에 이름을 쓰고 좋아하는 동물을 골라요. 아이마다 기록이 따로 쌓여요.
- 홈 화면의 **오늘의 미션**을 성공하면 별 1개를 받아요. 실패해도 별은 줄지 않고 다시 도전할 수 있어요.
- 별 5개를 모으면 다음 레벨로 올라가요.
- 열린 레벨은 레벨 지도에서 눌러 단어를 다시 연습할 수 있어요.

한 레벨의 미션 5개:

| 별 | 미션 |
| --- | --- |
| 1 | 배우기: 그림 8개를 모두 눌러 듣기 |
| 2 | 듣고 찾기: 8문제 중 6개 맞히기 |
| 3 | 짝 맞추기: 정해진 횟수 안에 짝 모두 찾기 |
| 4 | 듣고 찾기: 8문제 중 7개 맞히기 |
| 5 | 보스 미션: 배운 단어로 10문제 중 8개 맞히기 |

레벨은 동물, 과일, 색깔, 숫자, 몸, 탈것, 음식, 하늘과 자연 순서예요. 레벨 5부터는 보기와 카드가 늘어나요. 8단계를 다 깨면 모든 단어를 섞은 복습 레벨이 이어져요.

기록은 그 기기의 브라우저에 저장돼요. 다른 기기나 다른 브라우저에서는 처음부터 시작해요.

## 만들기

`index.html` 파일 하나로 되어 있어요. 발음은 브라우저에 들어 있는 음성 기능을 써요. `main` 브랜치에 올리면 Vercel이 자동으로 배포해요.
